# Migration from PhiGraph 3.9 to 4.0

1. Back up the repository, ledger and idempotency data.
2. Install PhiGraph 4.0.0 in a staging environment.
3. Replace new application imports with the stable public namespaces.
4. Keep existing `phigraph.core_v3` imports during gradual migration.
5. Validate the ledger chain.
6. Repair legacy chain metadata only if validation fails for a known release-candidate ledger.
7. Run application-specific replay and shadow tests.
8. Promote only after OIDC, PostgreSQL, backups and observability are validated in the target environment.

```python
from phigraph.migration import validate_ledger, repair_ledger

result = validate_ledger(".phigraph/ledger.json")
if not result["valid"]:
    result = repair_ledger(".phigraph/ledger.json")
assert result["valid"]
```
