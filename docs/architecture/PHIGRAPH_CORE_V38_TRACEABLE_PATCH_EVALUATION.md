# PhiGraph Core v3.8 — Traceable Patch Evaluation

The v3.8 pipeline binds repository evidence to a commit SHA and deterministic tree hash, represents issue–requirement–file–test–PR relations as an explicit graph, accepts provider-neutral model proposals, and evaluates unified diffs in disposable local copies. The source repository and remote providers are never modified. Statistical summaries use explicit 95% normal-approximation confidence intervals and must not be interpreted as proof of general superiority without a sufficiently broad corpus.
