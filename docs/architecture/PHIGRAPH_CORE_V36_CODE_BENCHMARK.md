# PhiGraph Core v3.6 — Code Benchmark

The v3.6 harness measures whether deterministic evidence gates prevent an agent report from being accepted when compilation or tests fail. The baseline accepts the agent declaration; governed mode executes allow-listed checks and blocks completion if evidence fails or remains unverified.

This is an initial benchmark harness, not yet a claim of superiority over commercial coding agents. Model integrations, task suites and statistically powered comparisons remain future work.
