# PhiGraph v0.8 Meta-Learning

The meta-learning layer evaluates each operational run and learns which
configuration performs best by domain.

## Performance score

- 30% statistical evidence
- 30% adversarial robustness
- 30% observed outcome
- 10% runtime efficiency

Only confirmed real-world outcomes should be used as strong meta-learning
evidence. The system recommends configurations; it does not autonomously deploy
them or execute operational actions.
